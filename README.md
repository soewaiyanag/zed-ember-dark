# Ember Dark

A neutral near-black dark theme for [Zed](https://zed.dev) with soft warm accents and an off-white cursor.

- Editor background `#191919`, text `#e8e6e3`
- Purple keywords, green strings, blue functions, amber types
- Off-white cursor
- Matching terminal palette

## Install

Open the command palette (`Cmd+Shift+P`), run `zed: extensions`, search for **Ember Dark**, and install it. Then pick it with `Cmd+K Cmd+T`.
